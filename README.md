# NovaDeskPro

NovaDeskPro es una plataforma web desarrollada con Django para la gestión de soporte técnico, inventario, entregas, monitoreo, impresión, notificaciones y reportes.

## Características principales

- Gestión de usuarios y roles.
- Administración de tickets de soporte.
- Inventario de activos tecnológicos.
- Registro de intervenciones técnicas.
- Gestión de entregas y movimientos de custodia.
- Monitoreo de equipos.
- Control de dispositivos de impresión y consumibles.
- Notificaciones internas.
- Reportes y paneles de control.
- Importación masiva de activos mediante Excel.

## Tecnologías

- Python 3.14
- Django 6
- PostgreSQL
- OpenPyXL
- Pillow
- ReportLab
- GitHub Actions
